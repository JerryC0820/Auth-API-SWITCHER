# 2.0.8

- 登录入口顺序调整为手动登录优先，登录弹层底部切换按钮改成“手动登录”在前、“扫码登录/扫码绑定”在后。
- 授权页底部友情链接新增“牛牛量化”入口，可直接跳转 `https://niuq.ainivox.cn/`。
- 当前设备本地卡片改为自动补传云端；检测到缺失或较新版本时，会在后台主动刷新当前设备云备份。
- 新电脑登录且本地为空时，检测到云端卡片会先弹出小确认窗；确认后立即转后台快速同步，不再要求一直停留在同步面板里等待。
- 云端下载改成批量导入并跳过当场额度探测，二次密码续跑会保留本次勾选的卡片集合，减少单张导入等待时间并避免后台续跑丢选择。
- 官网、下载页与安装包版本同步刷新到 2.0.8，保持对外展示版本与桌面端发行版本一致。
