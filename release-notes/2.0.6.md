# 2.0.6

- 继续收口 2.0 系列删除链路，单删、批量删除、全部删除和云端同步删除的确认弹窗与执行路径持续修复，补回无弹窗、点了无反应和慢删的问题。
- 补齐套餐型号识别，`pro5x / prolite` 统一识别为 `Pro 5x`，`pro20x / pro` 统一识别为 `Pro 20x`，减少空间卡片与授权展示里的计划名称错判。
- 修复网页登录与注册后的设备身份识别问题，浏览器端会更稳定提交设备标识，缺失历史设备记录时也会自动补齐，降低“未找到当前账号设备信息”的误报。
- 推荐切换与空间池交互继续收口，修复推荐切换覆盖大图标、`ENOTEMPTY` 清理失败、代理异常缺少明确提示、按应用记忆自动启动开关等一批易感问题。
- “空间已自动停用”提示面板调整为更克制的展示结构，保留原有逻辑，同时减少干扰并提高当前空间与最近探活信息的可读性。
- 公众号扫码登录补充微信接口权限识别，遇到 `api unauthorized / 48001` 时不再直接抛出原始报错，会明确提示当前公众号缺少带参数二维码接口权限，并自动切回小程序扫码。
- 官网公共导航新增 GitHub 入口，统一跳转到公开的 `Auth-API-SWITCHER` 发行仓，方便直接查看公开版本与发布说明；原码仓继续不对外暴露。
- 重新打包 Windows 稳定版，并同步刷新 GitHub Release、下载站稳定版说明与更新清单。
